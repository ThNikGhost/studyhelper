KWGT Widget Setup

Виджет следующей пары на домашнем экране Android через KWGT Pro

Рекомендуем: нативный виджет (APK)
Более простой способ — установите нативное Android-приложение (бесплатно, ~2 МБ).
Скачать APK из GitHub Releases
KWGT — альтернативный вариант с большей гибкостью настройки.

Что понадобится

  • KWGT Kustom Widget Maker Pro — из Google Play (~$5)
  • API ключ — включите в Настройках раздел «Виджет» и скопируйте ключ
  • Android 8.0+
1

Установите KWGT Pro

Откройте Google Play и установите KWGT Kustom Widget Maker (бесплатная версия) и KWGT Pro Key (разблокирует сохранение).

Важно: Без Pro Key вы не сможете сохранить виджет. Бесплатная версия позволяет только смотреть.
2

Добавьте виджет на рабочий стол

  • Долгое нажатие на рабочем столе → «Виджеты»
  • Найдите KWGT в списке
  • Выберите размер 4×2 и перетащите на рабочий стол
  • Нажмите на виджет — откроется редактор KWGT
3

Создайте Flow для загрузки данных

Flow — это автоматизация, которая загружает данные с сервера по расписанию.

  • В редакторе виджета нажмите вкладку «Flow» (значок молнии)
  • Нажмите «+» для добавления нового потока
  • Добавьте триггер: Cron → */30 * * * * (каждые 30 мин)
  • Добавьте ещё один триггер: On Load (при загрузке виджета)
Совет: 30 минут — оптимальный интервал. Более частые запросы разряжают батарею, но не дают пользы, т.к. расписание не меняется каждую минуту.
4

Добавьте WebGet action

Эта команда загружает JSON с данными о следующей паре.

  • В Flow нажмите «+ Action»
  • Выберите «WebGet»
  • В поле URL вставьте:
https://studyhelper1.ru/api/v1/widget/next-lesson?api_key=YOUR_KEY

Замените YOUR_KEY на ваш API ключ из настроек.

5

Сохраните в глобальную переменную

  • В настройках WebGet action найдите «Store to»
  • Выберите «Global Variable»
  • Имя переменной: data
  • Mode: Text
Совет: Глобальная переменная gv(data) будет содержать весь JSON-ответ. Формулы ниже будут извлекать нужные поля.
6

Настройте элементы виджета

Вернитесь на вкладку «Items» и добавьте текстовые элементы. Для каждого задайте формулу из раздела ниже.

  • Нажмите «+» → «Text»
  • В поле «Text» вставьте нужную формулу
  • Настройте шрифт, размер и цвет по вкусу
  • Повторите для всех элементов

Формулы KWGT

Нажмите на формулу, чтобы выделить. Вставьте в текстовый элемент KWGT.

Предмет
$wg(gv(data), json, .subject)$
Время
$wg(gv(data), json, .time_start)$ – $wg(gv(data), json, .time_end)$
Аудитория
$wg(gv(data), json, .location)$
Тип пары
$wg(gv(data), json, .lesson_type)$
Преподаватель
$wg(gv(data), json, .teacher)$
Обратный отсчёт
$if(wg(gv(data), json, .no_more_lessons) = true, Нет пар, Через wg(gv(data), json, .minutes_until) мин)$
Сегодня / дата (если пара в другой день)
$if(wg(gv(data), json, .is_today) = true, Сегодня, wg(gv(data), json, .date))$

Полезные советы

Обновление по расписанию

Flow с триггером */30 * * * * обновляет данные каждые 30 минут. Это оптимальный баланс между актуальностью и расходом батареи.

Тёмная/светлая тема

Для тёмного фона виджета используйте Shape → Rectangle с цветом #1c1c1e и скруглением углов 20dp.

Нажатие на виджет

В настройках виджета → «Touch» → «Open URL» → https://studyhelper1.ru/schedule. По нажатию откроется страница расписания.

Нет данных?

Используйте условие для пустого состояния:

$if(wg(gv(data), json, .no_more_lessons) = true, "🎉 Нет пар — свободный день!", wg(gv(data), json, .subject))$
